房东宽带慢、卡、转圈，但手上只有手机？这个 App 用手机就能把「到底哪一段慢」测出来。

## 先记住一句话

> **满格还慢 = 带宽问题；格少还慢 = 信号/信道问题。**

满格代表手机和路由器之间通畅，那卡就卡在路由器往外（房东那条线、套餐、别人在分）。
格少代表你和路由器之间就差，那是你自己能修的（位置、信道、频段）。

## 四项检测

| 卡片 | 测什么 | 能回答的问题 |
|---|---|---|
| ① 一键体检 | 分两段 ping：手机→路由器（网关）、手机→外网（223.5.5.5）。每段统计平均延迟、抖动、丢包 | 卡在「手机↔路由器」还是「路由器↔外网」？ |
| ② 周边 WiFi 拥堵 | 扫周围所有 AP，统计 2.4G 各信道被几个强信号占住 | 2.4G 该改成 1、6、11 里的哪个？要不要换 5G？ |
| ③ 测网速 | 真实上下行 Mbps（边下边滚动显示已下载 MB 与瞬时速度） | 房东这条线实测到底多少兆？够不够看 1080p？ |
| ④ 谁在连这个 WiFi | 扫同网段 1–254，识别设备类型、品牌、主机名、型号、开放端口 | 有几台设备在分带宽？有没有不认识的设备？ |

---

## ① 三档归因（App 会自动判）

| 判定条件 | 结论 | 你能做什么 |
|---|---|---|
| 第一跳 `丢包>15%` 或 `平均>40ms` 或 `抖动>60ms` | 手机 ↔ 路由器这一跳就不行 | 换位置、改信道 1/6/11、切 5G、关电池限制 |
| 第一跳正常，出网 `丢包>10%` 或 `平均>120ms` 或 `抖动>80ms` | 问题在路由器往外 | 拿数据找房东谈；高峰时段复测 |
| 两段都正常 | ping 漂亮但一用就卡 = 带宽不够 | 测速确认、看设备数、让房东换老路由器 |

## ④ 设备识别靠四条判据

1. **端口**：9100/631/515→打印机；62078→iPhone/iPad；3389/445/139→Windows；554/8009/7000/5000→电视盒子摄像头；22→NAS
2. **主机名**：`iphone`/`redmi`/`macbook`/`DESKTOP-xxx` 这类关键词
3. **TTL**：128→Windows 电脑；64→手机；255→网络设备
4. **HTTP 标题 / Server 头**：路由器、打印机、盒子后台页面标题里有型号

**踢人只能在路由器后台做。** App 里点「🔧 打开路由器后台」→ 找「已连接设备 / DHCP 客户端」→ 对上 IP 或 MAC → 禁用。

> Android 10 以后系统禁止普通 App 读别人的 MAC，所以很多行 MAC 显示「读不到（系统限制）」，遥控器后台能看到完整 MAC。

## 权限

| 权限 | 为什么 |
|---|---|
| `INTERNET` | 测速、读设备 HTTP 标题、ping |
| `ACCESS_NETWORK_STATE` | 读网关、DNS、频段 |
| `ACCESS_FINE_LOCATION` | Android 强制要求：扫周边 WiFi 列表必须给定位权限（不是用来定位你） |

## 能力边界（说实话部分）

- **手机端能改善的**：换位置、切 5G、改私有 DNS、关电池限制 —— 收益有限，但免费。
- **路由器端收益最大**：改 2.4G 信道到 1/6/11 里最空的、踢掉陌生设备、把老单频路由换掉 —— 需要后台密码（多半 `admin/admin` 或贴在路由器背面）。
- **带宽套餐**：只能拿数据谈。App 的「📋 复制全部报告」就是给你一份带数字的证据。
- 测速走 Cloudflare 节点，不是国内 CDN，实际刷国内视频通常比这个数好看一些。
