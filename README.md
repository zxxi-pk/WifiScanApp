# 出租屋 WiFi 体检

房东宽带慢、卡、转圈，但手上只有手机？这个 App 用手机就能把「到底哪一段慢」测出来。

## 先记住一句话

> **满格还慢 = 带宽问题；格少还慢 = 信号问题。**

满格代表手机和路由器之间通畅，那卡就卡在路由器往外（房东那条线、套餐、别人在分）。
格少代表你和路由器之间就差，那是你自己能修的（位置、信道、频段）。

---

## 四个检测，点哪个出在哪个下面

| 按钮 | 测什么 | 能回答的问题 |
|---|---|---|
| **① 一键体检** | 分两段 ping：手机→路由器、手机→外网 | 是「你和路由器」的问题，还是「路由器往外」的问题 |
| **② 扫周边 WiFi** | 周围所有 AP 的信号强度、信道、加密方式 | 信道挤不挤？2.4G 该改成 1 还是 11 |
| **③ 测网速** | 下行 / 上行 Mbps，实时显示已下载多少 MB | 真实带宽有多少？房东说的 100M 到了几 M |
| **④ 扫局域网设备** | 同网段所有在线设备 + 设备类型 | 都有谁在连？有没有不认识的在蹭 |

每个检测都是**边跑边出结果**：测速会显示「↓ 已下载 3.2 / 8.0 MB  当前 18.4 Mbps」；体检每收到一个 ping 回包就刷新；扫设备是找到一台立刻出一张卡。

## 怎么读结果

### 一键体检的三档结论

| 第一跳（手机→路由器） | 出网（→223.5.5.5） | 结论 | 谁能修 |
|---|---|---|---|
| 丢包 >15% 或 平均 >40ms 或 抖动 >60ms | — | 手机↔路由器就不行 | **你自己**（换位置、改信道、连 5G） |
| 正常 | 丢包 >10% 或 平均 >120ms 或 抖动 >80ms | 路由器往外这一段差 | 只能谈（但要先排除下面两件） |
| 正常 | 正常 | 延迟没问题，是带宽不够 | 看测速 + 设备数 |

### 测网速的判定

- **< 8 Mbps** — 基本就是「转圈」的原因，1080p 要 5–8 Mbps
- **8–25 Mbps** — 刷视频够，多人同时看或下大文件就卡
- **> 25 Mbps** — 带宽够用，卡的原因在延迟 / DNS / 有人占带宽

测的是 Cloudflare 云端节点，不是国内 CDN。所以刷国内视频的体感通常比这个数好看一些。

### 扫局域网设备的类型识别

不是只读 MAC 厂商。四路交叉判断：

1. **TTL** — 128 大概率 Windows，64 大概率手机/Android/iOS，255 是网络设备
2. **端口** — 9100/631/515 → 打印机；3389/445/139 → Windows；62078 → iPhone/iPad；8009/554/7000 → 电视盒子；22 → NAS
3. **主机名** — 反解 `xxx-PC` / `iPhone` / `DESKTOP-` 之类
4. **HTTP 页面标题** — 路由器、摄像头、打印机后台的 `<title>`，型号最靠谱的来源

「⚠ 未知」不代表没扫到，只代表这四路都没特征（很多 IoT 设备就是这样）。

## 四件能直接动手改的事

| 按钮 | 作用 | 值得做吗 |
|---|---|---|
| 🔧 **打开路由器后台** | 直接跳网关 IP（密码多半在路由器背面） | **收益最大**：改 2.4G 信道到 1/6/11、看已连接设备、禁掉陌生的 |
| ⚡ **换私有 DNS** | 跳到「私有 DNS」设置，填 `dns.alidns.com` | 治「网页转圈圈但测速正常」，收益中等 |
| 📋 **复制最近一份报告** | 把四项结果全拷出来 | 拿去给房东看，比说「卡」有用 |
| 📶 / 🔋 | WiFi 设置、关电池限制 | 防锁屏后 WiFi 被系统掐 |

## 关于「踢人」

**手机 App 踢不了人。** 这是硬边界，不是没做：

- 「已连接设备」那张表只存在于路由器里（DHCP 客户端列表 / 已连接终端），普通 App 读不到
- 踢人 = 在路由器后台点禁用，或者改 WiFi 密码让所有设备重连
- 本 App 的 ④ 扫局域网设备能告诉你有几台、大概是什么，**对上 IP/MAC 后去后台点禁用**

Android 10 以后系统禁止普通 App 读取别人的 MAC 地址，所以很多行 MAC 显示「读不到」——这是系统限制，路由器后台能看到完整 MAC。

## 权限

| 权限 | 为什么 |
|---|---|
| `ACCESS_FINE_LOCATION` | Android 规定：扫周边 WiFi 列表必须给定位权限 |
| `ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` | 读信号、触发扫描 |
| `INTERNET` / `ACCESS_NETWORK_STATE` | 测速、ping、读网关 |
| `usesCleartextTraffic` | 读路由器/摄像头后台的 http 页面标题 |

全部数据本地处理，不上传任何东西。

## 其他两个形态

**网页版测速**（不用装 App）：https://zxxi-pk.github.io/WifiScanApp/
只测上下行/延迟，读不到 dBm 和信道。

**Termux 脚本**（无 GUI，纯命令）：`wifi_scan.sh`，需要 `termux-api` 和 `jq`。
扫 2.4G/5G 信道、dBm、拥堵，输出建议信道。

---

## 能力边界（说实话）

- 手机端能改的很少：私有 DNS、切 5G、关电池限制
- 改信道、踢设备、限速 → **必须在路由器后台**，要密码（多数 `admin/admin` 或路由器背面贴纸）
- 带宽套餐、整栋楼共享一条线 → **只能谈**，但你可以拿出①②③④四个数据去谈
